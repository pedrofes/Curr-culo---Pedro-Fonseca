# Currículo Pedro Fonseca

## Sobre o projeto

Projeto de currículo desenvolvido em uma trilha de estudos sobre HTML e CSS.

## Objetivo

Desenvolver um currículo próprio através dos conhecimentos básicos sobre HTML e CSS.

## Tecnologias

- HTML
- CSS

## Conceitos aplicados

- Estruturação da página com HTML
- HTML semântico com `header`, `main`, `section` e `footer`
- Estilização da página com CSS
- Box Model
- Flexbox
- Responsividade com Media Queries
- Background com `background-image`
- Espaçamentos com `padding` e `margin`
- Cores e transparência
- Tipografia com `font-size`, `font-family`, `font-weight` e `line-height`
- Bordas, `border-radius` e `box-shadow`
- Estilização de links e uso de `:hover`
